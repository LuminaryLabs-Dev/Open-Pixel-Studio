# Open Pixel Studio — Store page draft

**Status:** Editorial draft for review. Not approved or published.

**Short description (under 120 characters)**

A focused pixel-art workspace for drawing, layering, animating, and exporting sprites.

**Long description**

Open Pixel Studio is a browser-based pixel-art editor from Luminary Labs. Work directly on a pixel canvas, organize artwork with layers, build frame-by-frame animations, and export sprites for use in your projects.

The workspace keeps the canvas central. Drawing tools, palette controls, the layer inspector, and animation timeline remain accessible without filling the screen with dashboard panels.

**Current features**

- Pencil, eraser, paint bucket, eyedropper, dither brush, lines, rectangles, and ellipses.
- Rectangular selection, pixel movement, undo/redo, zoom, and grid.
- Editable layers and frame-based animation with onion skin and preview.
- Built-in color palettes and HEX color selection.
- PNG frames, sprite-sheet PNG, animated GIF, atlas JSON, and editable `.npx` project exports.
- Self-contained browser build with a Luminary Labs-inspired workspace layout.

**Current limitations**

This is a browser-based editor, not a native desktop application. It does not yet include indexed color mode, linked cels, a tilemap editor, scripting, or full Aseprite feature parity. Save `.npx` files for reliable project backups; browser storage may depend on local browser permissions.
