## Capture provenance and edit decisions

**Exact application source file:** `Nexus-Pixel-Studio-v0.2.0-Standalone.html`, SHA-256 recorded in `evidence/manifest-sha256.json`.

Source captured using Chromium via Playwright's video recording at 1280×720, 25 fps, in three independent takes. The studio's own menus, file input, mouse drawing, color fields, layer controls, timeline and export controls were operated through normal browser input. No source-code modifications, offscreen simulated editor overlays or fabricated UI were used.

The three source takes are each about 22 seconds. The master uses time ranges **0.5s–20.5s** from each in order, cut at 20s and 40s. The lower-third Open Pixel Studio title and section labels are overlaid externally as promotional graphics; they are not built-in UI. An original low-volume electronic score was added externally. The silent master is also supplied. Do not describe the master as an uninterrupted 60-second drawing session.

## Evidence limits

This is a promotional product walkthrough, **not a performance benchmark**, native desktop proof, or proof of every claimed feature. Screen captures are from a local browser session using the packaged v0.2.0 app. `raw/` stores separate, unedited source takes. `images/Screenshot-*` are direct editor captures; `images/Open-Pixel-Studio-*` promotional composites contain clearly separate branding around real captures.

App features not shown should only be claimed from current source or QA evidence, not invented from marketing artwork. Current source does not support a claim of full Aseprite parity, indexed mode, tilemaps, linked cels, or native desktop distribution.
